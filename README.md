# Palace Pal

[PalacePal](https://github.com/PunishXIV/PalacePal) 的台服移植版。在**死者宮殿**、**天之御柱**、**正統優雷卡**中標示可能的陷阱與受詛咒藏寶箱位置，以及本層的寶箱、通道與再生裝置。

需要另外安裝 **Splatoon** 才能繪製世界疊加層，請從同一個插件庫安裝。

## 功能

- **陷阱／受詛咒藏寶箱標示**：在世界疊加層上標出已知或可能的位置。自己確認過的（踩到觸發、用魔陶器：全景或感知寶藏照出、挖到）畫實色；只來自下載、匯入或舊紀錄的畫成較淡、並畫在下層（透明度可調）。用了全景／感知寶藏後可只留實際位置、隱藏其餘。
- **兩種模式**：
  - **線上模式**：從 Palantir 社群伺服器下載其他玩家回報的位置，**只下載、不上傳**。要有足夠玩家回報過的點才顯示（預設陷阱 4 次、受詛咒藏寶箱 2 次，可調，0＝全部顯示）。設定視窗顯示伺服器連線狀態，連不上時只顯示自己記錄的位置。
  - **離線模式**：不連線，只顯示自己找到的位置。
- **陷阱觸發偵測**：踩到陷阱時，依陷阱特效與遊戲已解析好的動作效果記下位置（只讀取、不改動遊戲資料）。遊戲改版後對不上時只停用這一項，其他功能照常。
- **陷阱種類標示**：魔陶器：全景（正統優雷卡為魔科學器：全景）生效期間，在照出來的陷阱上方標出地雷、誘餌陷阱、弱化陷阱等種類（可在「陷阱」區取消）。
- **寶箱**：標出本層附近的金、銀、青銅寶箱，青銅寶箱可另外標出擬態怪（只偵測得到早期樓層的）。
- **通道與再生裝置**：標出傳送用的通道（可在啟動後改為亮綠色填色），以及再生石塚／再生燈籠／再生裝置（預設關）。
- **本層小地圖視窗**（預設關）：畫出本層房間格子、自己與小隊成員所在房、傳送／再生裝置是否可用、各房寶箱；可調大小、背景不透明度、鎖定位置、滑鼠穿透。資料讀遊戲自己的地圖，不下載也不上傳。
- **匯入**：匯入 `*.pal` 位置檔，可復原匯入。
- **提供給其他插件的 IPC**：陷阱與受詛咒藏寶箱位置（分已確認／未確認），以及這一層實際看得到的點位（例如 BossModReborn 會使用）。

## 指令

- `/pal`：開啟設定視窗（第一次使用要先完成設定）。
- `/pal test-connection`（或 `/pal tc`）：測試與 Palantir 伺服器的連線。

## 台服版的修改

- 線上模式改從 Palantir 社群伺服器下載陷阱與寶箱位置，只下載、不上傳；加上回報次數門檻。
- 陷阱與受詛咒藏寶箱標示分「自己確認過／未確認」兩態，並有我方的確認資料庫（只記真的踩到或用魔陶器照出來的點）。
- 新增踩到陷阱時依動作效果記錄位置（含正統優雷卡）。
- 新增全景照出的陷阱種類標示、再生裝置標示、本層小地圖視窗。
- 伺服器連不上時顯示連線狀態並退避重試，不再無聲重連。
- 遊戲改版後陷阱特效的特徵碼對不上時，插件照常載入、只停用對應的記錄功能。
- 新增給其他插件用的「已確認／未確認」與「目前看得到的點位」IPC。
- Splatoon 安裝提示改指台服插件庫；聊天訊息改由 framework 執行緒依序送出。
- 多處降低記憶體用量。
- 介面繁體中文化（修正台服客戶端載不到中文資源的問題）。
